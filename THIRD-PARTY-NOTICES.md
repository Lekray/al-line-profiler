# Сторонние компоненты

**В этом репозитории нет ни одного чужого двоичного файла.** Всё, что здесь лежит в
собранном виде (`dist/`), — собственная сборка проекта под лицензией MIT, той же, что и
весь остальной код.

Ниже — единственная сторонняя зависимость и объяснение, почему она не поставляется
вместе с инструментом.

## Microsoft.Diagnostics.Tracing.TraceEvent

| | |
|---|---|
| Назначение | чтение событий ETW: подписка на провайдер платформы и разбор сохранённых `.etl` |
| Правообладатель | © Microsoft Corporation |
| Исходный проект | https://github.com/microsoft/perfview |
| Пакет | https://www.nuget.org/packages/Microsoft.Diagnostics.Tracing.TraceEvent |
| Где берётся | из уже установленной платформы: `Service\Add-ins\NavEtwReceiver\` |
| Поставляется в составе проекта | **нет** |

### Почему не поставляется

Библиотека сменила лицензию в середине своей истории, и граница проходит ровно по тем
версиям, которые встречаются на серверах NAV:

| Версии | Лицензия |
|---|---|
| по 2.0.30 включительно | MICROSOFT SOFTWARE LICENSE TERMS — MICROSOFT .NET LIBRARY (проприетарная) |
| с 2.0.31 (12.12.2018) | MIT |

Версия, которую поставляет NAV 2018, — **1.0.39.0 от 08.10.2015**, то есть из первой
половины таблицы. Её лицензия (файл `License-Stable.rtf` внутри пакета NuGet) в разделе
«SCOPE OF LICENSE» прямо запрещает «publish the software for others to copy». Выкладывать
этот файл в публичный репозиторий нельзя.

Отдельная ловушка для проверяющего: ссылка на лицензию в старом пакете
(`fwlink/?LinkId=329770`) сегодня перенаправляет на современную страницу, где написано про
MIT. Перенаправление сделано задним числом; лицензия, под которой файл был выпущен, лежит
**внутри самого пакета** и говорит другое. Смену лицензии Microsoft провела коммитом от
12.11.2018 «Harmonize the license in the source and in the nuget packages».

### Почему это не мешает работе

Приёмник собирается **на целевом сервере** против той библиотеки, которая там уже есть.
Проверено сборкой против версий **1.0.11, 1.0.26, 1.0.39 и 2.0.64** — используемая часть
API одинакова во всех, исходник не меняется. Привязка к точной версии получается по
построению, а не подбором: ссылка на эту сборку строгоименная и связывается только с
совпадающей версией.

Установка копирует библиотеку **с того же сервера** в папку надстройки рядом с приёмником
(NAV не просматривает соседние папки надстроек, каждая обязана быть самодостаточной).
Копирование файла в пределах машины, где он уже лицензирован в составе платформы,
распространением не является.

### Проверено

Файл `Microsoft.Diagnostics.Tracing.TraceEvent.dll` из поставки NAV 2018
(2 107 696 байт, SHA-256 `061d00fe7eb38719ef6f4a1bc0f3afcbb2a08f0247632cc5f29f557e4604e799`)
**побайтно совпадает** с `lib/net40/...` из публичного пакета NuGet версии 1.0.39. Microsoft
положила в платформу стоковый файл, а не особую сборку, — происхождение проверяющий может
подтвердить сам, не обращаясь к нам.

### Нативные компоненты пакета

В современных пакетах TraceEvent есть ещё `KernelTraceControl.dll`, `msdia140.dll` и
библиотеки времени выполнения C++ (`build/native/`). На них действует **не MIT**, а
отдельное соглашение «MICROSOFT SOFTWARE LICENSE TERMS — MICROSOFT WINDOWS PERFORMANCE
TOOLKIT». Профайлер их не использует и не поставляет: ни разбор символов, ни
перелогирование трассировки ему не нужны.

## Платформа

Объекты C/AL обращаются к штатным типам .NET Framework (`mscorlib`, `System`) и к
виртуальным таблицам самой платформы NAV. Ни то ни другое в репозиторий не входит и
условиями этого проекта не покрывается — это часть лицензированной установки.
